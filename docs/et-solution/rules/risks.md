# 探索性测试反模式清单（破坏路径）

> 覆盖率保证"点到了"，本清单保证"用容易出问题的姿势点了"。执行时逐项打勾，不适用项标注 EX-OUT-SCOPE。

## A. 重复/快速操作
- [ ] A1 支付按钮连点 ≥3 次 → 不重复入账、不重复扣款、不崩溃
- [ ] A2 兑换按钮连点 → 不重复扣积分、不重复发券
- [ ] A3 弹窗打开按钮连点 → 不叠弹、不白屏
- [ ] A4 数量 +/- 长按/连点 → 数量/金额正确，不出现负数

## B. 导航与状态跳转
- [ ] B1 浏览器后退/前进 → 视图正确、不丢状态
- [ ] B2 直接改 URL hash（含非法 hash）→ 回落正确，不白屏
- [ ] B3 新开同 URL tab → 状态按产品预期（内存态重置 or 同步）
- [ ] B4 支付成功后按返回 → 不重复触发支付
- [ ] B5 深链接直入 #/checkout / #/order 空态 → 友好提示或回落

## C. 刷新与中断
- [ ] C1 各视图 mid-flow 刷新 → 不白屏、不报错
- [ ] C2 弹窗打开时刷新 → 正常回到初始态
- [ ] C3 请求/DemoConsole 操作中按 Esc / 点遮罩 → 不挂起、不出现半操作状态

## D. 中途切环境
- [ ] D1 加菜 → 切 EN → 结账 → 切回 zh → 支付，文案不回错、明细 note 不被回溯翻译
- [ ] D2 结账页切老人模式 → 布局不溢出、按钮可点
- [ ] D3 桌面/移动断点来回切 → 无错乱元素

## E. 极端数据与边界
- [ ] E1 余额 0 / 差 1 分 / 刚好等于档位 / 档位 +1
- [ ] E2 兑换券 50% 上限边界（cap-1 / cap / cap+1）
- [ ] E3 DemoConsole 输入 0 / 负数 / 极大值 / 非数字
- [ ] E4 购物车 0 件 / 1 件 / 多件，单品最大可点数量
- [ ] E5 多笔退菜叠加、退菜金额 > 余额 → 不出现负积分
- [ ] E6 过期瞬间/全部过期/部分过期后操作

## F. 键盘与无障碍
- [ ] F1 Tab 能遍历所有交互元素，焦点无 trap
- [ ] F2 Esc 关闭所有 Dialog，二次 Esc 不报错
- [ ] F3 Enter 触发聚焦按钮；Space 切换 checkbox
- [ ] F4 所有按钮/图片有可访问名（aria-label 或可见文本）

## G. 视觉与文案
- [ ] G1 中/英长文案不溢出、不遮挡
- [ ] G2 空态/零态/满态都有友好提示
- [ ] G3 Toast/反馈文案在 250ms~3s 内出现并消失
- [ ] G4 颜色对比度可接受（快速主观判断 + 后续 a11y 专项）
- [ ] G5 不出现字面 i18n key（`xxx.yyy` 形式）

## H. 控制台与网络
- [ ] H1 全程无 `console.error`（EX-KNOWN 白名单除外）
- [ ] H2 无 `pageerror` / unhandledrejection
- [ ] H3 无静态资源 4xx/5xx
- [ ] H4 无失败的 fetch/XHR（Demo 项目无后端则跳过）
